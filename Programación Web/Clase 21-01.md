# Componentes fundamentales del Desarrollo Web
## HTML
Lenguaje de marcado utilizado para estructurar contenido en la web. Define encabezados, párrafos, imágenes, enlaces, etc.
## CSS (Cascading Style Sheets)
Se utiliza para estilizar el contenido definido por HTML. Controla: colores, fuentes, espaciado, diseño, etc.
## JavaScript
Lenguaje de programación que añade interactividad a las páginas web. Ejemplo: formularios dinámicos, sliders, validaciones
## HTTP/HTTPS
Protocolos para la transferencia de datos entre el navegados y el servidor

### Etiquetas
Marcan el inicio y fin de un elemento
### Atributos
Proporcionan información adicional sobre una etiqueta
### Contenido
Información entre etiquetas
